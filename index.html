          AI 분류 · 영감

          Anthropic API 키를 넣으면 Claude가 메모를 분류하고, 할 일을 뽑고, 링크 내용을 읽어 정리해요. 키는 이 기기에만 저장돼요. 없으면 기기 안의 간단한 규칙으로 동작해요. 잠근 분류의 메모는 어떤 경우에도 AI로 보내지 않아요.

          보관함 잠금

          알림

          앱이 열려 있거나 켜질 때 알려줘요. 앱이 꺼져 있어도 꼭 울려야 하는 건 할 일·북마크의 📅 캘린더 버튼으로 캘린더에 넣으세요.

          공유 버튼으로 저장하기

          안드로이드·크롬북: 앱을 설치하면 공유 메뉴에 ‘냅킨’이 생겨요.
          아이폰: 단축어 앱 → 새 단축어 → 설정(ⓘ)에서 공유 시트에서 보기 켜기 → 동작 ① URL 인코딩(단축어 입력) ② 텍스트: [URL 인코딩된 텍스트] ③ URL 열기. 이제 사파리·인스타 등에서 공유 → ‘냅킨’을 누르면 바로 저장돼요.

          아이폰 앱: 알림은 앱이 꺼져 있어도 울려요. 공유 메뉴의 ‘냅킨’, 홈 화면 위젯, 액션 버튼(단축어 ‘냅킨에 적기’)으로 바로 적을 수 있어요.
