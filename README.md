# 냅킨 메모

카페에서 냅킨에 적듯 떠오른 생각을 급히 적어두면,

1. **알아서 분류**하고 (분류명 · 키워드 · "이럴 때 다시 보면 좋음")
2. 나중에 **"지금 이런 상황이야"** 라고 하면 쌓인 메모 중 영감이 될 것을 골라 엮어준다.

데스크탑과 아이폰에서 똑같이 쓰는 PWA(웹앱)다. 설치하면 앱처럼 독립된 작은 창으로 열린다.

## 화면

**냅킨(입력칸)은 어느 화면에서든 아래에 떠 있다.** Enter는 줄바꿈, **저장** 버튼으로 저장(컴퓨터는 ⌘/Ctrl+Enter).
할 일인지, 링크인지, 그냥 생각인지는 적은 내용을 보고 알아서 나눈다.
링크를 붙이면 **다시 알려줄 때**를 고를 수 있고, **＋ 연재** 버튼으로 연재(예: 클라이밍 N회차)를 고르거나 새로 만들어 그 안에 이어 쓴다.

| 탭 | 하는 일 |
|---|---|
| 홈 | 지금 챙길 것(기한 된 할 일 · 리마인드 링크) + 최근에 적은 것 |
| 할 일 | 메모에서 찾은 할 일. 기한 있는 것은 기한 순 + 알림 + 📅 캘린더, 기한 없는 것은 **하나씩 '첫 행동'을 제안** |
| 북마크 | 링크만 따로. 링크 페이지를 읽어 제목 · 한 줄 요약 · 분류. 링크마다 ⏰ 리마인드 |
| 서랍 | 분류별 메모 · 검색 · 새 분류 · 이름 바꾸기 · **정리 제안 받기**. 위쪽에 **연재 기록** 타임라인과 **여러 회차에 반복되는 말** |
| 영감 | 상황을 적으면 관련 메모 + 뜻밖의 메모를 골라 엮은 아이디어(💡)를 제안 |
| ⚙︎ (오른쪽 위) | 글씨체, AI 정리, 비밀 보관함, 알림, 백업 |

## 잠근 분류 (보관함)

- 비밀번호 · 계좌 · 주민번호 · 카드번호 · 통관부호가 보이면 **기기 안에서** 먼저 걸러 `보관함`에 넣는다. AI로 가기 전에 판별하므로 AI는 이 내용을 받지 않는다.
- 어떤 분류든 `🔒 이 분류 잠그기`로 잠글 수 있다. 잠긴 메모는 분류 · 할 일 · 영감 · 정리 제안 어디에도 AI로 보내지 않는다.
- 설정에서 PIN을 정하면 잠긴 메모를 암호화한다(공개키로 암호화, PIN으로 푼 개인키로만 복호화). 잠겨 있어도 새 민감 메모는 바로 암호화된다. 열어둔 보관함은 5분 뒤나 앱을 벗어나면 다시 잠긴다.
- **PIN을 잊으면 복구할 수 없다.** 짧은 PIN은 기기를 가진 사람이 시간을 들이면 풀 수 있으니 6자리 이상을 권한다.

## 알림에 대해

서버 없이 동작하므로, 앱이 열려 있거나 다시 열릴 때 **지금 챙길 것**과 시스템 알림(허용 시), 앱 아이콘 배지로 알려준다.
앱이 꺼져 있어도 반드시 울려야 하는 일은 📅 버튼으로 **캘린더에 넣으면** 기기 캘린더 알림이 울린다.

## 설치

### 배포

`main`에 푸시하면 GitHub Actions가 GitHub Pages로 배포한다.
처음 한 번 저장소 **Settings → Pages → Source: GitHub Actions** 로 설정해야 한다.
주소: `https://<계정>.github.io/napkin_memo/`

로컬 실행: `npm install && npm run dev`

### 아이폰

**아이폰 앱(권장)**: 위젯에서 바로 적기, 챙길 것 위젯, 액션 버튼, 공유 메뉴, 알림이 모두 된다. 설치 방법은 [`ios/README.md`](ios/README.md).

웹앱만 쓸 때: Safari로 주소를 열고 공유 → **홈 화면에 추가**.
단, 단축어 등으로 `?q=` 주소를 열면 **사파리**에서 열리고, 홈 화면에 추가한 웹앱과는 저장소가 따로라 메모가 섞이지 않는다.
위젯 · 공유 메뉴로 적으려면 아이폰 앱을 쓴다.

### 안드로이드

크롬에서 설치하면 공유 메뉴에 **냅킨**이 바로 생긴다(Web Share Target).

### 데스크탑 (Chrome / Edge)

1. 주소창 오른쪽 **설치** 아이콘 → 앱으로 설치
2. 작업 표시줄/독의 앱 아이콘을 우클릭 → **빠르게 적기** 를 고르면 작은 위젯 창(`?widget`)이 열린다.
3. 창을 작게 줄여 화면 구석에 두면 위젯처럼 쓸 수 있다.

## 기기 간 옮기기

현재는 서버가 없어 기기마다 따로 저장된다. 설정의 **내보내기 → 가져오기**(JSON)로 옮긴다.
(중복은 자동으로 건너뜀)

## 구조

```
src/store.ts      메모 · 할 일 · 분류 저장 (localStorage)
src/detect.ts     기기 안 판별: 링크 · 민감정보 · 연재 번호 · 날짜/할 일
src/pipeline.ts   저장 → 잠금/북마크/메모 → 분류 · 할 일
src/vault.ts      잠근 분류 암호화 (RSA-OAEP + AES-GCM, PIN → PBKDF2)
src/reminders.ts  지금 챙길 것 · 시스템 알림 · 배지 · 캘린더(.ics)
src/ai.ts         Claude 호출: 분류+할 일 / 링크 읽기(web fetch) / 첫 행동 / 연재 패턴 / 영감 / 정리 제안
src/local.ts      API 없이 동작하는 규칙 분류 · 유사도 검색 · 반복 키워드
src/views/        할 일 · 북마크 · 서랍 화면
src/main.ts       적기 · 영감 · 설정 · 시작
public/        PWA manifest, service worker, 아이콘
```
