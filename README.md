# 냅킨 메모

카페에서 냅킨에 적듯 떠오른 생각을 급히 적어두면,

1. **알아서 분류**하고 (분류명 · 키워드 · "이럴 때 다시 보면 좋음")
2. 나중에 **"지금 이런 상황이야"** 라고 하면 쌓인 메모 중 영감이 될 것을 골라 엮어준다.

데스크탑과 아이폰에서 똑같이 쓰는 PWA(웹앱)다. 설치하면 앱처럼 독립된 작은 창으로 열린다.

## 화면

| 탭 | 하는 일 |
|---|---|
| 적기 | 한 칸짜리 냅킨. `Enter` 저장, `Shift+Enter` 줄바꿈. 저장하는 순간 백그라운드에서 분류 |
| 서랍 | 분류별 모아보기 · 검색. 분류 이름을 누르면 직접 바꿀 수 있음 |
| 영감 | 상황을 적거나 프리셋을 누르면 관련 메모 + 뜻밖의 메모를 골라주고, 이를 엮은 아이디어(💡)를 제안 |
| ⚙︎ | API 키, 백업/가져오기, 빠른 입력 안내 |

## AI (선택)

설정에 Anthropic API 키를 넣으면 Claude(`claude-opus-5`)가 분류와 영감 찾기를 한다.
키가 없거나 오프라인이면 기기 안의 간단한 키워드 규칙으로 동작한다. 나중에 키를 넣고
"AI로 다시 분류"를 누르면 된다.

- 키와 메모는 **그 기기의 브라우저 저장소에만** 저장되고, AI 호출은 브라우저에서 Anthropic API로 직접 간다.
- 그래서 이 앱은 **본인만 쓰는 용도**를 전제로 한다. (공개 서비스로 운영하려면 서버에서 키를 보관해야 함)

## 설치

### 배포

`main`에 푸시하면 GitHub Actions가 GitHub Pages로 배포한다.
처음 한 번 저장소 **Settings → Pages → Source: GitHub Actions** 로 설정해야 한다.
주소: `https://<계정>.github.io/napkin_memo/`

로컬 실행: `npm install && npm run dev`

### 아이폰

1. Safari로 위 주소 열기 → 공유 → **홈 화면에 추가**
2. (위젯처럼 쓰기) **단축어** 앱에서 새 단축어:
   - `입력 요청` (프롬프트: "뭐가 떠올랐어?")
   - `URL`: `https://<계정>.github.io/napkin_memo/?q=` 뒤에 `제공된 입력` 변수
   - `URL 열기`
3. 홈 화면 편집 → 위젯 → **단축어** 위젯에 이 단축어를 올려두면 한 번 탭으로 바로 적을 수 있다.
   (액션 버튼이 있는 기종은 액션 버튼에 연결해도 좋다)

### 데스크탑 (Chrome / Edge)

1. 주소창 오른쪽 **설치** 아이콘 → 앱으로 설치
2. 작업 표시줄/독의 앱 아이콘을 우클릭 → **빠르게 적기** 를 고르면 작은 위젯 창(`?widget`)이 열린다.
3. 창을 작게 줄여 화면 구석에 두면 위젯처럼 쓸 수 있다.

## 기기 간 옮기기

현재는 서버가 없어 기기마다 따로 저장된다. 설정의 **내보내기 → 가져오기**(JSON)로 옮긴다.
(중복은 자동으로 건너뜀)

## 구조

```
src/store.ts   메모 저장 (localStorage)
src/ai.ts      Claude 호출: 분류 / 영감 (structured output)
src/local.ts   API 없이 동작하는 규칙 분류 · 유사도 검색
src/main.ts    화면
public/        PWA manifest, service worker, 아이콘
```
